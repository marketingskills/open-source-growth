- Name a fork or derivative product "open-source-growth", "repo-growth-operator", or any confusingly similar name

## What you can do

- Fork the code and ship your own thing under your own name
- Refer to `open-source-growth` accurately in articles, tutorials, comparison pieces, and integrations
- Use the name in good-faith bug reports, support discussions, and developer documentation
