# Contributing

Thanks for your interest in improving `open-source-growth`.

## How to contribute

### New skills

1. Create `skills/<new-skill-name>/SKILL.md` with YAML front matter (name, description).
2. Include example prompts and trigger phrases.
3. Add any reference docs in `skills/<new-skill-name>/references/`.
4. Update the root `README.md` skills table.
5. Open a PR.

### Improvements to existing skills

- Fix bugs, improve prompts, add examples, expand reference docs.
- Keep the [ethical growth policy](skills/repo-growth-operator/references/ethical-growth-policy.md) in mind.

### Scripts

- Python scripts go in `skills/<skill-name>/scripts/`.
- Include a `Usage:` comment at the top.
- Prefer stdlib where possible.

## PR guidelines

- One change per PR.
- Include a clear description.
- Update CHANGELOG.md for user-facing changes.
- If adding a skill, include an example output.

## Code of conduct

Be respectful. This is a small open-source project. Assume good faith.
