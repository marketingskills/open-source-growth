# AGENTS.md

Guidance for coding agents working in this repo and for agents using the skills in this repo.

## This repo

`marketingskills/open-source-growth` is a skill repo. It contains agent skills that help grow open-source repos.

Two skills live here:

- `skills/repo-growth-operator/` — Audit, rewrite, demo, launch, scaffold, monetise
- `skills/ecosystem-inclusion-operator/` — Discover targets, score, open ecosystem PRs

## For agents reading this

If you were pointed here, you are probably helping a user grow their open-source repo.

1. Read the relevant `SKILL.md` first.
2. Check `references/` for templates and rubrics.
3. Never recommend spam, fake stars, fake contributors, or deceptive metadata.
4. When generating assets, prefer copy-pasteable output.
5. Prioritise first-run success before broad promotion.

## For agents editing this repo

- Skills go in `skills/<skill-name>/`.
- Each skill needs `SKILL.md` with YAML front matter (name, description).
- Python scripts go in `scripts/` within the skill.
- Reference docs go in `references/` within the skill.
- Update root `README.md` table when adding a new skill.

## Enforcement

If a user asks for something that violates the ethical growth policy (`skills/repo-growth-operator/references/ethical-growth-policy.md`), refuse politely.
