# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-17

### Initial release

- `repo-growth-operator` skill with 7 modes: repo-audit, readme-upgrade, demo-builder, launch-pack, trust-scaffold, marketplace-optimise, oss-to-paid-funnel.
- `ecosystem-inclusion-operator` skill with discover, score, prepare-pr, open-pr, follow-up, and summarise commands.
- Reference documents for scoring, README template, launch pack, directory submission, monetisation, and ethical growth.
- Python scripts for automated auditing, scoring, target discovery, and progress tracking.
- Example outputs for `marketingskills/seo` as a case study.
- `.repo-growth/` progress log specification for durable `/loop` workflows.
