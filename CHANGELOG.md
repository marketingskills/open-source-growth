# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-17

### Initial release

- `repo-growth-operator` skill with 8 modes: repo-audit, readme-upgrade, demo-builder, launch-pack, trust-scaffold, marketplace-optimise, oss-to-paid-funnel, social-proof.
- `ecosystem-inclusion-operator` skill with discover, score, prepare-pr, open-pr, star-target, follow-up, and summarise commands.
- Reference documents for scoring, README template, launch pack, directory submission, monetisation, ethical growth, and social proof actions.
- Python scripts for automated auditing, scoring, target discovery, star actions, and progress tracking.
- Example outputs for `marketingskills/seo` as a case study.
- `.repo-growth/` progress log specification for durable `/loop` workflows.
- `AGENTS.md` for agent-native repo navigation.
- `install.sh` curl|bash installer with coloured output.
- `TRADEMARK.md` brand protection.
- Dual-audience README (human + agent).
- Cross-skill star/social-proof via `gh` CLI with explicit user confirmation.
- Platform-agnostic install: `npx skills add`, `curl | bash`, or direct git clone.
