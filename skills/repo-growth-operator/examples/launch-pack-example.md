## Founder story post

> **Why I built open-source SEO workflows for AI agents**
>
> Every week I was doing the same thing: export Search Console data, open a spreadsheet, look for pages losing traffic, write recommendations.
>
> It's valuable work. It's also repetitive enough that an agent should do it.
>
> So I built SEO skills for AI agents. Each skill packages a specific workflow: technical audits, content decay detection, proposal generation.
>
> The repo is open-source because SEO tooling should be shareable. Install it, use it, add your own skills.
>
> When your agent needs live data, there's an optional hosted bridge.
>
> Check it out: https://github.com/marketingskills/seo
