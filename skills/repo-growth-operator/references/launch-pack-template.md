# Launch Pack Template

Generate one section per channel. Each must be tailored to the specific repo — never generic.

## LinkedIn post

- Hook: Problem + open-source solution.
- Body: What it does, who it's for, one example prompt.
- CTA: Try it (install command).
- Image: Hero screenshot or demo GIF.

## X thread

- Tweet 1: Hook (one-line + link).
- Tweet 2: The painful problem.
- Tweet 3: The solution with one prompt example.
- Tweet 4: Install command and quick start.
- Tweet 5: Who it's for + call for feedback.

## Hacker News title

- 3–5 options.
- Must be factual, not promotional.
- Best format: "Show HN: [What it does in plain language]"

## Reddit posts

For each subreddit, produce a separate post with:
- Title matching the subreddit's norms.
- Self-post with context, not a link drop.
- One example prompt in the body.
- Open question for discussion.

## Product Hunt tagline

- 8–12 words.
- Job-to-be-done + key differentiator.

## GitHub release notes

- Semantic version, date.
- What's new (for users).
- What's changed (for contributors).
- Full changelog link.

## Founder story post

- Why you built it.
- Who it's for.
- What makes it different.
- What you hope the community does with it.

## Email to friends / users

- Short, personal.
- "I built this, would love your feedback."
- Link to repo.
- Ask for one specific thing (try it, star it, open an issue).
